# Memory Postcards — 那些有光的日子

[Experience the exhibition](https://hhzc087-blip.github.io/memory-postcards-demo/)

43 photographs, 43 independently authored fictional memories and 14 composed Hero postcards. Dates, places and relationships are narrative inventions, not real biographies or photographic metadata. This public repository contains only the reviewed static exhibition, with no private engineering history, personal photos, editor database or credentials.
